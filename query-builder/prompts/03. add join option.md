# Nova Tarefa

Com base nos métodos que já existem de configuração de parâmetros para construção de uma sintaxe sql, adicione também opções de configuração de JOINs entre duas ou mais tabelas. 

Importante lembrar que uma vez que o join entre tabelas ocorra, devemos permitir que o usuário selecione, crie colunas calcuadas e filtre colunas de todas as tabelas do JOIN.

## Configuraçao de JOINs

Jornada do usuário:

1. Selecione qual tabela será seu público de partida
2. Deseja usar variáveis de outras tabelas?
    2.1 Sim? Mostra outras tabelas que não seja a selecionada como público inicial e permite configuração do JOIN
    2.2 Não? Fluxo normal de configuração

### Opções de JOINs
*   LEFT JOIN
*   INNER JOIN

Toda operação de LEFT JOIN deve permitir que o usuário configure o methodo de junção `ON` uma ou mais colunas
