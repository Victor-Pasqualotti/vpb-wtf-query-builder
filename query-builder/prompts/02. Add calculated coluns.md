# Nova Tarefa

Com base nos métodos que já existem de configuração de parâmetros para construção de uma sintaxe sql, adicione também opções de configuração para criação de colunas calculadas. 

Aqui estão algumas opções de colunas calculadas:

## Colunas calculadas

### Row number
*   row_number
    *   overs
    *   Partition By

### Colunas calculadas qu exigem group by e habilitam opção de HAVING
*   max
*   min
*   count
*   count(distinct `coluna`)
*   sum
*   avg
*   concat

### Outros
*   coluna calculada por operações matemáticas:
    * `+` - soma de duas ou mais colunas
    * `-` - subtração de duas ou mais colunas
    * `=` - comparação de igualdade
